## ✦ Current & Recent Projects

### 🌙 [MoonScribe](https://github.com/HaydenDev3/moonscribe) — current flagship

A private, local-first writing studio for long-form fiction, worldbuilding, collaboration, and book design.

MoonScribe brings manuscript writing, characters, relationships, timelines, moodboards, story planning and finished-book design into one workspace. It includes offline-first storage, optional sync, rich-text writing, exports and a Three.js-powered 3D book preview.

`React 19` `TypeScript` `Vite` `Tiptap` `IndexedDB` `Node.js` `SQLite` `WebSockets` `Three.js` `Tauri`

**Live:** [moonscribe.cc](https://moonscribe.cc)

### 🌐 [Portfolio 2026](https://github.com/HaydenDev3/Portfolio-2026)

My current personal portfolio project — a home for my work, experiments, projects and developer identity.

`Web Development` `UI / UX` `Portfolio`

### 🔐 Aether

A privacy-focused social platform built around private communication, clean UI and invite-based communities. The project explores full-stack social features, authentication, messaging and a simpler alternative to large public social platforms.

`React` `TypeScript` `Fastify` `MongoDB` `Realtime`

### 🤖 [Ollie CLI](https://github.com/HaydenDev3/ollie_cli)

A local-AI command-line project built around experimenting with Ollama and developer-focused AI workflows.

`Local AI` `Ollama` `CLI` `Developer Tools`

### 🛠️ [dscaffold](https://github.com/HaydenDev3/dscaffold)

A small developer-tooling project focused on making Discord project setup and scaffolding quicker and less repetitive.

`Developer Tools` `Discord` `Automation`

### 🛡️ Aja

A security-focused Discord bot project built around community protection, moderation and administration. Aja represents a large part of my earlier Discord development work and the systems experience that led into my newer full-stack projects.

`Discord.js` `Node.js` `Security` `Moderation`
